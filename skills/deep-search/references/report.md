# Deep research report

Two pages at most: about 900 words of body text, excluding the source list. Cut background the user didn't ask for before cutting evidence.

## Doc skeleton (create before researching)

Title: the question, rewritten as a short headline.
Byline line: today's date and "Researched with Exa and Parallel".
One pending block per section below, each with a one-line intent.

## Sections

1. **Bottom line** (3 to 5 sentences). The direct answer, with its overall confidence. If the honest answer is "it depends" or "not known", say that here.
2. **Key findings** (4 to 8 bullets). One fact per bullet, each with an inline source link and a confidence label (confirmed / likely / unconfirmed). Exact figures with units and dates.
3. **Where sources disagree** (only if they do). What each side says, who says it, and which is better supported and why.
4. **Not confirmed** (only if needed). What you looked for and couldn't verify, and why (no source, paywall, login wall, conflicting data).
5. **Sources** (numbered). Title, publisher or site, date, link. Primary sources first. Each source once, however many mirrors exist.

Optional, only when it helps the user decide: a small comparison table (no more than 6 rows).

## Style

- Plain words, short sentences. No filler, no restating the question.
- "As of [date]" for anything that changes (prices, versions, roles, status).
- Don't mention tools, engines or the research process, except in the byline.

## When not to use a Doc

If the user asked for the report in chat, a file or another app, put it there with the same sections. If Claude Docs isn't connected, say so in one line and write the report in chat (or as a document in Claude Code).
