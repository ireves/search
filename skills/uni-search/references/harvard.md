Harvard references, Cite Them Right style (the version most UK universities use). Read only when references = Harvard.

IN-TEXT (replaces inline links; plain text, no hyperlink)
- (Surname, Year) or Surname (Year) explains... Organisation as author: (Ofcom, 2021).
- 2 authors: (Smith and Jones, 2024). 3: (Smith, Jones and Brown, 2024). 4+: (Smith et al., 2024).
- No date: (Ofcom, n.d.). Same author, same year: (Smith, 2024a), (Smith, 2024b), lettered in reference list order.
- Several sources for one point: (Smith, 2024; Ofcom, 2021).
- Direct quote: add the page when the source gives one: (Smith, 2024, p. 12).
- Confidence labels (confirmed/likely/unconfirmed) still apply; put them after the citation.

REFERENCE LIST (heading "Reference list"; replaces "Sources")
Alphabetical by first author's surname, else organisation, else title. Each source once. Accessed date = the day a worker read it (today), written "7 October 2026". Italics with *...*.
- Web page: Surname, I. (Year) *Title of page*. Available at: URL (Accessed: date). No date: (n.d.) in place of (Year).
  No personal author -> organisation in the author slot. No organisation either -> *Title of page* (Year) Available at: URL (Accessed: date).
- Journal article with DOI: Surname, I. and Surname, I. (Year) 'Title of article', *Journal Title*, 22(4), pp. 300-314. Available at: https://doi.org/... (no accessed date).
  Without DOI: same, then Available at: URL (Accessed: date).
- Online news: Surname, I. (Year) 'Title of article', *Newspaper*, Day Month. Available at: URL (Accessed: date).
- Online report (government, organisation): Organisation (Year) *Title of report*. Available at: URL (Accessed: date).
- Online video (YouTube): Poster (Year) *Title*. Day Month uploaded. Available at: URL (Accessed: date).
- Book or ebook with publication details: Surname, I. (Year) *Title*. Edition (if not the first). Publisher.
- Thesis: Surname, I. (Year) *Title*. PhD thesis. University. Available at: URL (Accessed: date).
Year: the year the source was published, or for a web page the year it was last updated, from the page, its REF line or a digest line for that url (an "updated 2026-10-01" note counts). "n.d." only when none of these gives a date.
Authors: Surname, Initials. Reference list names every author, never "et al." (et al. is only for in-text citations of 4+ authors). Join with commas and "and" before the last. A digest or result shows "and N more" or "list cut" -> the source check asks that page for the full author list.

NEVER INVENT DETAILS
- Use only what the worker's REF lines or a digest line for the same url give. Missing author -> organisation; missing year -> "n.d."; missing volume, issue, pages or edition -> leave that element out.
- Never guess a DOI, initials or a page number. A DOI must come from the page or result.
- Search-engine or mirror pages (ResearchGate copies, Exa library pages) -> reference the original publisher or DOI.

At the end of the reply (not in a Doc's body), one line: "References follow Cite Them Right Harvard (n.d. for undated sources, every author named); check your university's guide for other local differences."
