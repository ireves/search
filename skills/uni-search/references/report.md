Research report spec. Max 3 pages: ~1,400 words body excluding sources. Cut background before evidence.

Skeleton (Claude Doc; create before researching): title = question as short headline; byline = today's date + "Researched with Exa and Parallel"; one pending block per section with a one-line intent.

Sections in order:
1. Bottom line: 3-6 sentences; direct answer + overall confidence; say "it depends"/"not known" if true; premise false -> say so here.
2. Key findings: 5-10 bullets; one fact each; inline source link; label confirmed/likely/unconfirmed; exact figures with units and dates.
3. Analysis (only if the question asks why/how/what it means): short paragraphs linking cited findings; mark your own inferences ("This suggests..."); no new facts without a source.
4. Where sources disagree (only if they do): each side, who says it, which is better supported and why.
5. Not confirmed (only if needed): what was sought, pages checked, why unverified (not stated, paywall, login, conflicting data). Only after the SKILL.md step 4 gap check.
6. Sources: numbered; title, publisher/site, date, link; primary first; each source once regardless of mirrors. Only sources that passed the step 6 source check.
Optional: one comparison table, <=8 rows, only if it helps a decision.

Style: plain words, short sentences, no filler, don't restate the question. "As of <date>" for changing facts. Don't mention tools/engines/workers/process except in the byline.

Destination Chat -> same sections in the reply, then the cost line. Claude Docs not connected -> say so in one line; report in chat.
