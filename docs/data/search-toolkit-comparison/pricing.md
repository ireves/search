## Composio: how it charges

Source: https://composio.dev/pricing and https://composio.dev/instant (verified).

- **Hobby (free)**: 100,000 tool calls and 50,000 trigger events a month, unlimited connected accounts, 3 team members, 2,000 requests/min. Hard cap: usage pauses at the limit, no surprise bills. Meta tools (tool search, schemas etc.) are free.
- **Pro ($29/month)**: includes a $29 monthly usage credit (no rollover); past the free amounts, tool calls are **$0.0003 each** ($0.30 per 1,000) and triggers $0.003. 10,000 requests/min.
- **Enterprise**: custom committed volume.
- **Composio-managed apps** (shared OAuth apps): only 20,000 of the 100,000 free calls, then $0.0005/call. Add-ons: direct execution outside a session +$0.0001/call (10k free), proxy execute +$0.0002 (1k free), sandbox execution +$0.0001 (10k free), etc.
- **Instant accounts / Instant Tools**: toolkits (Parallel, Firecrawl, TinyFish, Serper, Context.dev, Akta, Crustdata, ScrapeCreators, Browser Use, etc.) that run on **Composio's own provider accounts**, so no API key is needed. The provider's usage charge is deducted from your **Composio balance (wallet) at 0% markup**, on top of the normal tool-call charge. When the balance is exhausted, Instant calls stop with HTTP 402 (`Metering_WalletBalanceExhausted`); balance checks are asynchronous, so it is not a strict per-call cap. Connected accounts that use your own keys keep working.
- **What this means for the benchmark**: the shared wallet is empty, so every Instant toolkit fails with 402 until someone tops it up. Tools on the user's **own** accounts (EXA_SEARCH and EXA_GET_CONTENTS via the user's Exa key) still work and bill the user's Exa account directly ($0.007 per search, observed). Composio's own Search toolkit (COMPOSIO_SEARCH_WEB, _TAVILY, _DUCK_DUCK_GO, _FETCH_URL_CONTENT) also still works and shows no per-call cost; it counts only as ordinary tool calls.
- **Effective cost via Composio** = provider list price + $0.30 per 1k calls on Pro once past the free allowance (or $0 within Hobby's 100k). Browser Use Instant runs reserve `max_cost_usd` up front: in the benchmark, a $0.50 cap on 16 runs reserved $8 although actual use was about $0.19.
